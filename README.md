# Context Bot

Telegram-бот для извлечения текста из PDF-документов и создания краткого
изложения. Англоязычный текст суммаризируется моделью BART, а текст на других
языках предварительно переводится на английский.

## Возможности

- приём PDF-файлов через Telegram;
- извлечение текста со всех читаемых страниц;
- определение языка и автоматический перевод на английский;
- создание краткого изложения с помощью `facebook/bart-large-cnn`;
- перевод результата на русский, арабский или английский;
- хранение списка пользователей для администраторской рассылки.

## Требования

- Python 3.10 или новее (для локального запуска рекомендуется Python 3.11–3.12);
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather);
- несколько гигабайт свободного места для моделей Hugging Face;
- доступ в интернет при первом запуске для загрузки моделей.

## Быстрый старт

```bash
git clone https://github.com/setterwars/Context-bot.git
cd Context-bot

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

Создайте локальный файл с настройками:

```bash
cp .env.example .env
```

Укажите в `.env` токен, полученный у BotFather:

```dotenv
BOT_TOKEN=your_telegram_bot_token
BOT_ADMIN_USERNAME=your_telegram_username
CONTEXT_BOT_DATA_DIR=data
```

Загрузите переменные и запустите бота:

```bash
set -a
source .env
set +a
context-bot
```

Альтернативный способ запуска после установки пакета:

```bash
python -m context_bot
```

> При первом запросе будут загружены модели BART и MarianMT. Поэтому первая
> обработка документа займёт больше времени, чем последующие.

## Настройки

| Переменная | Обязательна | Значение по умолчанию | Назначение |
|---|---:|---|---|
| `BOT_TOKEN` | да | — | токен Telegram Bot API |
| `BOT_ADMIN_USERNAME` | нет | `ssllvvtt` | username с доступом к администраторской команде |
| `CONTEXT_BOT_DATA_DIR` | нет | `data` | каталог для runtime-данных и временных загрузок |

Секреты и содержимое каталога `data/` исключены из Git. Не добавляйте токен
бота в исходный код или коммиты.

## Структура проекта

```text
Context-bot/
├── src/context_bot/
│   ├── app.py          # настройка логирования и запуск polling
│   ├── bot.py          # Telegram-команды и обработчики сообщений
│   ├── config.py       # чтение настроек из переменных окружения
│   ├── pdf.py          # извлечение текста из PDF
│   ├── storage.py      # локальное JSON-хранилище пользователей
│   └── summarizer.py   # перевод и суммаризация текста
├── tests/              # модульные тесты
├── .env.example        # пример локальной конфигурации
├── pyproject.toml      # метаданные проекта и зависимости
└── LICENSE.md
```

Runtime-файлы создаются автоматически:

```text
data/
├── users.json
└── uploads/
```

Временные PDF удаляются после обработки, в том числе при возникновении ошибки.

## Проверка проекта

Тесты используют стандартный модуль `unittest`:

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

Проверка синтаксиса всех модулей:

```bash
python -m compileall -q src tests
```

## Ограничения

- PDF без текстового слоя (например, сканы) не распознаются: OCR пока не
  поддерживается.
- Длинный текст ограничивается размером входа используемых моделей.
- Список пользователей хранится в локальном JSON-файле; для нескольких
  одновременно работающих экземпляров бота потребуется база данных.
